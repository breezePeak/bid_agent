# Bid Agent 3D · 标书指挥舱

基于 **Three.js + Vite** 的标书全流程 3D 态势大屏，实时展示：

- 全 pipeline 阶段状态（与 `pipeline_registry` 对齐）
- 子 Agent 工位 / 排队 / 休息 / 失败
- 主 Agent 统筹消息、Goal、事件流、材料与 Issues 摘要

## 启动

```bash
cd frontend-3d
npm install
npm run dev
```

浏览器打开：http://127.0.0.1:5174

默认代理后端 `http://127.0.0.1:7860`（与主前端一致）。

- 后端可用 → 自动进入 **实时连接**，轮询 `/api/status`、`/api/agent/activity`、`/api/agent/goal`
- 后端不可用 → 自动进入 **演示模式**，循环模拟全流程 + Agent 活动

## 操作

| 操作 | 说明 |
|------|------|
| 拖拽 / 滚轮 | 环绕、缩放场景 |
| 点击阶段节点 / 左侧列表 | 镜头聚焦该阶段 |
| 点击 Agent 卡片 | 镜头切到 Agent 区 |
| 总览 / 聚焦当前 / Agent 区 | 镜头预设 |
| 自动环绕 | 总览模式下缓慢公转 |
| 演示模式 / 实时连接 | 切换数据源 |
| 快捷键 `1` `2` `3` | 总览 / 当前 / Agent |
| `D` / `L` / `Space` | 演示 / 实时 / 环绕开关 |

## 视觉结构

1. **中央全息核心**：整体进度驱动的水晶与光柱  
2. **弧形阶段轨道**：21 个阶段节点 + 进度光带 + 数据粒子流  
3. **Agent 湾区**：主 Agent 中枢、左右工位、排队走廊、休息区  
4. **HUD**：玻璃拟态面板，阶段进度、舰队、事件、Goal  

## 构建

```bash
npm run build
npm run preview
```

产物在 `dist/`。按项目约定，本目录前端由开发者自行构建部署；agent 改代码后会提交源码。
