# 炼丹阁 · 标书全流程 3D

基于 **Three.js + Vite** 的标书态势大屏，用唐风丹殿场景展示：

- 与流水线对齐的工序节点与进度  
- 掌炉真人、列队 / 升殿道众  
- 八卦炉结丹、灵力波、黄金标书终局  
- Web Audio 音景（炉火、结丹、终局、UI；可静音）  

## 启动

```bash
cd frontend-3d
npm install
npm run dev
```

浏览器打开：http://127.0.0.1:5174  

默认代理后端 `http://127.0.0.1:7860`（与主 Web 一致）。

| 后端 | 模式 |
|------|------|
| 可用 | **观火**：开场三宝门真实上传 → 建工作空间 → 启流水线；轮询状态 / Agent / Goal |
| 不可用 | **演法**：开场三宝门模拟投料 → 本地演示一整轮；**停在成丹**，需「重新炼制」再开 |

### 开场三宝门

进入页面时从天而降三块面板：**招标文件 / 公司资料 / Word 模板**。

- 演法：点面板或「一键投料」模拟；「开炉炼制」后跑演示  
- 观火：选文件上传；「开炉炼制」会 `start-run` + `/api/upload` + `start-pipeline`  
- 「跳过 · 直接观览」不上传，仅看场景  

> 浏览器需用户交互后才播放声音（首次点击页面即可）。

## 操作

| 操作 | 说明 |
|------|------|
| 拖拽 / 滚轮 | 环绕、缩放 |
| 底栏视角 | 总览 / 殿前 / 殿内 / 丹炉 / 列队 / 工序 / 侧视 / 俯视 / 殿后 |
| 放大 / 缩小 | 镜头推近推远 |
| 环游 | 御道 → 入殿 → 丹炉 → 工序环视 |
| 灵力波 | 强制播放水平灵力波（建议俯视） |
| 静音 | 开关音效 |
| 演法 / 观火 | 切换演示与实时数据源 |
| 快捷键 `1`–`9` | 总览 / 当前 / 列队 / 殿内 / 丹炉 / 侧视 / 俯视 / 殿后 / 殿前 |
| `=` `-` | 放大 / 缩小 |
| `D` / `L` / `Space` | 演法 / 观火 / 环游 |

工序完成时会有结丹飞升 + 毛笔字提示；全流程完成后旋合出黄金标书，可「重新炼制」或「继续观览」。

## 视觉结构

1. **唐风三层大殿 + 御道**：逐层收分、青灰瓦、朱红柱、格扇窗  
2. **殿心八卦炉**：三足双耳、八卦盘、炉火与阵纹  
3. **弧形工序轨**：节点状态 + 进度带 + 数据流  
4. **道众**：掌炉面朝丹炉；排队朝殿、升殿朝炉  
5. **HUD**：工序列表、指标、事件、Goal  

## 构建

```bash
npm run build
npm run preview
```

产物在 `dist/`。按项目约定，本目录由开发者自行构建部署；agent 改代码后提交源码即可。
