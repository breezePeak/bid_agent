# 旧计划废止说明

以下旧设计已被代码回退和产品方向纠正同时废止：

```text
先改造全量编写 Plan
→ 再切换全量编写 Writer
→ 最后才开发旧投标书改写
```

废止原因：

1. 用户原有全量编写已经可用；
2. 本次需求是新增标书改写；
3. 旧设计要求先修改原有全量编写，风险和工期均不必要；
4. 旧设计让旧投标书功能到很后面才可测试；
5. 旧设计把新目录错误地设计为参考旧目录；
6. 用户真实要求是先按新招标书生成新目录，再按新章节读取旧标书；
7. 旧设计前后端长期分离，不符合每个 PR 可人工验收的要求。

