# PR-04：改写方案编辑、搜索补充、确认与污染治理

## 1. 唯一目标

用户可以调整当前章节使用哪些旧段落、如何使用、哪些缺失内容需要补写，必要时先搜索公开资料，解决旧项目污染后确认精确改写方案。

本 PR 不执行正文。

## 2. 控制面

新增：

```text
chapter_rewrite_states
chapter_rewrite_plan_revisions
chapter_rewrite_confirmations
chapter_rewrite_events
```

命令：

```text
bid_rewrite.plan.generate
bid_rewrite.plan.update
bid_rewrite.plan.search
bid_rewrite.plan.confirm
bid_rewrite.plan.reopen
```

所有更新是结构化操作，不接受任意整份 JSON 覆盖。

## 3. 支持的编辑操作

```text
select_legacy_block
unselect_legacy_block
change_block_usage
update_instruction
set_strategy
add_new_content_item
remove_new_content_item
bind_evidence
unbind_evidence
resolve_pollution
```

## 4. 补充搜索

用户对某个缺失内容点击“补充查询”：

```text
确定查询目标
→ 校验不是企业事实/业绩/人员/承诺
→ 调用现有 Tavily 研究服务
→ 发布 EvidenceBatch
→ 将 exact Evidence ID 绑定到改写方案
→ 新建 plan revision
→ 不自动确认
```

搜索失败保留旧 revision。

## 5. 污染治理

确认前扫描所有选中原文。

Finding：

```text
type
block_id
source_text
suggested_action
replacement_fact_id
status
```

未解决的以下风险阻断确认：

```text
旧项目名称
旧采购人
旧地区
旧年份/日期
旧工期
旧人员
旧数量
旧系统名称
旧产品/标准版本
旧合同承诺
```

允许替换值必须来自已确认的新项目事实或新招标原文。

## 6. 确认

确认请求绑定：

```text
chapter_id
expected_chapter_revision
plan_revision
plan_hash
blueprint_hash
legacy_bid_index_hash
global_context_hash
chapter_context_hash
principal_id
```

依赖变化后状态变为 stale，不能执行。

## 7. 前端

“改写逻辑”升级为可编辑：

- 勾选/取消旧段落；
- 查看整段原文；
- 设置直接复用、修改复用、重组复用、重新编写；
- 查看每个新要求是否覆盖；
- 添加补写项；
- 发起补充查询；
- 处理污染 finding；
- 查看 revision 历史；
- 保存草稿；
- 确认当前方案。

## 8. 自动化测试

- 每种 edit op；
- 悬空 block/section；
- stale content hash；
- coverage 下降提示；
- 搜索成功与失败；
- 禁搜企业事实；
- replacement 只能来自 confirmed fact；
- unresolved pollution 阻断；
- exact plan confirmation；
- CAS 冲突；
- 刷新/重启恢复；
- 无关资料变化不 stale；
- full_write 无 rewrite commands；
- 前端冲突和恢复。

## 9. 人工验收

1. 删除系统推荐的一段旧内容；
2. 增加另一段旧内容；
3. 将策略从直接复用改为修改复用；
4. 为缺失标准发起搜索；
5. 解决旧采购人和旧年份；
6. 刷新页面，revision 保留；
7. 两个浏览器同时修改，后提交者收到冲突；
8. 确认方案；
9. 修改当前章上下文，方案变 stale；
10. 本 PR 不出现“开始改写”执行结果。

## 10. Definition of Done

- [ ] 用户可完整编辑改写方案；
- [ ] 搜索发生在正文前；
- [ ] exact revision/hash 确认；
- [ ] 污染未解决不能确认；
- [ ] full_write 不受影响；
- [ ] CI 全绿；
- [ ] 未开始 PR-05。
