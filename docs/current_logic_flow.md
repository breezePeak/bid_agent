# 标书 Agent 流程逻辑版本导航

> 更新日期：2026-07-21

本页是流程文档的稳定入口。流程逻辑已经分为 V1 现行实现与 V2 目标架构，避免把规划中的能力误认为已经上线。

| 版本 | 状态 | 定位 | 文档 |
|---|---|---|---|
| V1 | 当前运行 / 冻结维护 | 现有工作流、Agent、材料、质量门禁和状态文件的实际行为 | [current_logic_flow_v1.md](./current_logic_flow_v1.md) |
| V2 | 阶段 A 进行中 / 尚未切换 | Agent 控制面、唯一流水线执行内核、SQLite 控制状态与两阶段迁移计划 | [current_logic_flow_v2.md](./current_logic_flow_v2.md) |

## 当前应以哪个版本为准

- 排查现有系统、理解当前 API 或修复线上问题时，以 **V1** 为准。
- 进行架构重构、接口设计和迁移开发时，以 **V2** 为准。
- V2 只有在迁移、回归和验收全部通过后，才能升级为新的“当前实现真相源”。

## 维护规则

- V1 只记录已存在的行为和必要缺陷修复，不再加入新的并行编排或状态模型。
- V2 按阶段记录“未开始 / 进行中 / 已验收”，不能仅因代码合入就标记完成。
- 涉及行为切换时，先更新 V2 状态与验收证据，再修改本页的现行版本指向。
