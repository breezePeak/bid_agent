## 当前应以哪个版本为准

- 当前 API、CLI、页面操作与问题修复一律以 **V3** 为准。
- V1/V2 API、迁移工具、兼容状态和旧执行入口均不存在；旧路径按未注册路由处理。
- 发现不含 `workspace/v3` 的旧工作区时应清理；不得迁移、读取或恢复其状态。

## 维护规则

- V1/V2 不再接受功能、缺陷或兼容维护；其文档仅作不可变历史说明。
- V3 是唯一允许演进的运行时；不得重新引入双运行时、旧路径代理或旧状态读取。
