# 标书 Agent 流程逻辑版本导航

> 更新日期：2026-07-26

本页是流程文档的稳定入口。系统已进入 V2-only 切换，V1 仅保留为历史归档与迁移取证资料，不能再作为 API、CLI 或运行时控制依据。

| 版本 | 状态 | 定位 | 文档 |
|---|---|---|---|
| V1 | 已废弃 / 历史归档 | 仅供历史取证和故障追溯；旧工作区应删除，禁止作为运行时真相源 | [current_logic_flow_v1.md](./current_logic_flow_v1.md) |
| V2 | 当前运行架构 / 切换验收中 | Agent 控制面、唯一流水线执行内核、SQLite 控制状态与迁移验收 | [current_logic_flow_v2.md](./current_logic_flow_v2.md) |
| V3 | 已确定目标架构 / 待实施 | 保留 V2 控制面，重构项目理解、双模式文档契约、按需研究、全文责任规划、内容单元、整合和严格渲染 | [current_logic_flow_v3.md](./current_logic_flow_v3.md) |

## 当前应以哪个版本为准

- 当前 API、CLI、页面操作与问题修复一律以 **V2** 为准。
- V3 是下一代目标架构，详细实施顺序以 [v3_development_plan.md](./v3_development_plan.md) 为准；在完成验收和切换前不得把 V3 文档误认为当前运行事实。
- 发现 V1 状态文件或旧工作区时应直接清理；不得迁移、读取或恢复 V1 路由、活动工作区或第二套状态机。
- V2 仍须完成迁移、回归和发布验收；验收未完成不等于允许回退到 V1 接口。

## 维护规则

- V1 不再接受功能、缺陷或兼容维护；仅作为不可变历史说明。
- V2 按阶段记录“未开始 / 进行中 / 已验收”，不能仅因代码合入就标记完成。
- V3 开发期间允许代码短暂并存，但正式切换后必须删除 V1/V2 兼容路径和被 V3 替代的内容链，禁止保留双运行时。
- 涉及行为切换时，先更新 V2 状态与验收证据，再修改本页的现行版本指向。
