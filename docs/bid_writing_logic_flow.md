# 标书编写统一逻辑流程

本文描述目标实现，不代表当前临时实现。唯一的章节写作核心是用户手动点击“生成草稿”后触发的章节 Agent 流程；其他入口只能顺序调用该核心，不能另行实现分析、检索、生成、校验或提交。

## 总体入口与调度

```mermaid
flowchart TD
    A[写作入口] --> B{入口类型}
    B -->|生成草稿| C[单章写作核心]
    B -->|对话要求写正文| C
    B -->|章节工作台一键编写| C
    B -->|选择多章节编写| D[后台批量调度]
    B -->|一键生成所选章节| D
    B -->|一键生成整份标书| E[后台整份标书调度]

    D --> F[服务端展开为有序叶子章节]
    F --> G[按目录顺序逐章调用单章写作核心]

    E --> H[解析全部可写叶子章节]
    H --> G

    C --> I{单章是否成功提交新版本}
    G --> I
    I -->|否：失败或等待人工| J[暂停当前任务，不启动下一章]
    I -->|是| K{是否还有章节}
    K -->|是| G
    K -->|否且来自整份标书| L[整合全文]
    K -->|否且来自多章节/所选章节| M[任务完成]
    L --> N[全文校验]
    N --> O[渲染 Word]
    O --> P[交付校验与下载]
```

## 公共单章写作核心

```mermaid
flowchart TD
    A[接收章节 ID、指令、幂等键和上下文引用] --> B[校验叶子章节、工作区和版本]
    B --> C[读取全局事实与章节上下文]
    C --> D[Agent 分析章节目标、目录位置和上下游关系]
    D --> E[生成或读取本章写作提纲]
    E --> F{提纲及权限允许写作？}
    F -->|否| G[返回等待人工确认事件]
    F -->|是| H[按需查看其他章节只读详情]
    H --> I[判断现有资料是否足够]
    I --> J{需要公开检索？}
    J -->|是| K[检索、筛选并记录可用资料]
    J -->|否| L[跳过检索]
    K --> M[流式输出 Agent 思考与正文]
    L --> M
    M --> N[校验正文、事实约束和上下文版本]
    N --> O[原子提交到中间文档]
    O --> P{head 内容版本增加？}
    P -->|否| Q[返回提交失败事件]
    P -->|是| R[返回已提交事件及正文版本]
```

单章核心产生的分析、检索、思考、正文、校验、提交和错误事件，是所有入口展示 Agent 过程的唯一来源。

## 批量任务状态流

```mermaid
stateDiagram-v2
    [*] --> queued: 创建任务并展开叶子章节
    queued --> running: Worker 领取首章
    running --> running: 当前章成功提交\n领取下一章
    running --> paused: 当前章等待人工确认\n或执行失败
    paused --> queued: 用户处理后重试当前章
    paused --> cancelled: 用户取消
    queued --> cancelled: 用户取消
    running --> cancelled: 当前安全提交完成后停止
    running --> succeeded: 所有章节均已提交
    succeeded --> [*]
    cancelled --> [*]
```

批量 Worker 只做以下工作：维护队列、选择当前叶子章节、调用公共单章写作核心、持久化事件与检查点、确认版本增长后推进下一章。它不得复制单章 Agent 流程，也不得将“模型已回复”或“检索已完成”当作章节成功。

## 入口与职责对应

| 入口 | 调度职责 | 正文生成职责 |
| --- | --- | --- |
| 手动“生成草稿” | 无；只启动当前叶子章节 | 直接调用公共单章写作核心 |
| 对话触发写正文 | 无；只启动当前叶子章节 | 直接调用公共单章写作核心 |
| 章节工作台“一键编写” | 无；只启动当前叶子章节 | 直接调用公共单章写作核心 |
| 选择多章节编写 | 展开、排序、逐章调度、暂停/重试 | 每章调用公共单章写作核心 |
| 一键生成所选章节 | 展开、排序、逐章调度 | 每章调用公共单章写作核心 |
| 一键生成整份标书 | 遍历全部叶子章节；完成后整合与交付 | 每章调用公共单章写作核心 |

## 前后端职责

| 责任 | 后端 | 前端 |
| --- | --- | --- |
| 章节生成、检索、校验、提交 | 执行公共单章写作核心并持久化结果 | 不实现生成逻辑 |
| 批量/整份标书 | 持久化队列、顺序调度、恢复、暂停和取消 | 创建任务及发送重试/取消指令 |
| 实时过程 | 发布真实单章执行事件 | 订阅事件并显示在对应章节 Agent 聊天框 |
| 章节展示 | 返回当前章、阶段、错误和正文版本 | 打开真实当前叶子章节；目录圆点反映任务状态 |

目录圆点默认灰色；排队或执行中为蓝色；提交成功为绿色；失败或暂停为红色。前端不得创建虚假的“正在处理”提示；显示文案必须来自后台的真实任务状态或公共单章服务事件。
